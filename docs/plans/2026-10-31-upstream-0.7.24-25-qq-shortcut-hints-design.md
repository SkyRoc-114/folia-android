### 2.2 QQ 批次（origin/main，精确缺口 38 提交）

- 判定方法教训：`git cherry <head> <upstream>` 第二参数**只收单个 commit**，范围语法会报 unknown commit；正确做法 `git rev-list --no-merges A^..B` 循环逐个 `git cherry` 判 patch-id。本次复核结果：`970ef5be^..d1d11bf7` 内 **38 提交全部缺失**；d1d11bf7 之后到 main tip（578efcd5）仅剩 .289 已移植两笔（patch-id 不同因适配）+ 1 chore，无新缺口。
- 内容：QQ 网页扫码登录通道（a875f44e/d1d11bf7）、QQ 写操作全链路（点赞/unlike/订阅/歌单/g_tk/comm/QIMEI）、NetEase weapi RSA key 修复、KuGou unlike/KRC 歌词/云列表、「暂时无法播放」可诊断化追踪、native POST 无 body (970ef5be)、移动渲染优化（MSAA off、30FPS 默认、暂停停帧 dd29154f）。
- 策略：按拓扑序逐个 cherry-pick；预期冲突面 qqTransport/nativeBridge/i18n；每个冲突语义级人工解决，禁止 `-X theirs` 盲并；每 5-8 个提交跑一次定向 vitest + tsc 中检。
- 注意：dd29154f（MSAA off/30FPS）与 §2.3 兜底设计有重叠，移植时以本设计为准合并语义，避免双重钳制打架。

### 2.3 Android 性能兜底（雾笺/町景）

- 接入既有体系：#929 的 `src/utils/lyricRenderQuality.ts` resolver 模式 + `useAndroidLayoutSettingsStore.liteModeEnabled` 轻量模式。
- 钳制规则（Android 壳生效，桌面不动）：
  - 町景：画质档位钳到低档、MSAA 关（其自带画质设置保留 UI，生效值被钳制并在描述里注明）；
  - 雾笺：雾层分辨率层取最低档（1/8 层），着色器预热照常（编译成本一次性）；
  - lite 模式开：两者额外禁用氛围后处理/景深散景这类纯装饰 pass（若上游有独立开关则置最低，否则跳过 pass）。
- 随机换样式池**不**回避重样式（用户决策），兜底交给钳制。
- 复查点：雾笺擦痕遮罩走 **WebGL2**——Android 7 老 WebView 可能无 WebGL2；实施时确认上游有无 `getContext('webgl2')` 失败降级，无则在兜底任务补「WebGL2 不可用→整样式回退骨架追踪/隐藏该样式」。

## 3. 快捷键显示（shortcut hints）设计

### 3.1 数据与判定

- **store**：`useInteractionSettingsStore` 新键 `shortcutHintsMode: 'auto' | 'on' | 'off'`，默认 `'auto'`；**必须**用 `const SHORTCUT_HINTS_MODE_KEY = 'shortcut_hints_mode'` 常量模式声明（.288 lyrics_antialias 契约教训），同步更新 storeContract 快照测试。
- **原生（Android）**：`FoliaNativePlugin.java` 增：
  - `InputManager.registerInputDeviceListener` → `onInputDeviceAdded/Removed`：按 `InputDevice.sources` 位测 `SOURCE_KEYBOARD`（含 `isFullKeyboard`）/`SOURCE_MOUSE` 分类，聚合后经插件事件通道 `onHidDevicesChanged` 推给 Web（键鼠各一布尔）；
  - `getConnectedHidDevices()` 同步查询（Web 启动时先查再订，防丢事件）；
  - 与上游 Spotify 登录段共存纪律：不动既有 41 个 PluginMethod。
- **Web hook**：`useHidConnection()` → `{ keyboardConnected, mouseConnected, hidConnected }`：
  - Capacitor Android 壳：插件查询+事件；
  - Electron/桌面：恒 true（桌面必有键鼠，行为与现状一致，零回归）；
  - Web 兜底（无插件环境）：`matchMedia('(hover: hover) and (pointer: fine)')`（复用 `useSupportsFinePointer`）感知鼠标；纯键盘接入在 Web 层无媒体查询可用，接受「按一下才识别」的降级（用户已选原生为主）。
- **生效值 resolver**：`resolveShortcutHintsVisible(mode, hidConnected)` = `mode === 'on' ? true : mode === 'off' ? false : hidConnected`；纯函数便于直测。
