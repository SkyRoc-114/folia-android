# 实施计划：v0.7.24/25 全量迁移 + QQ 批次 + 快捷键显示

> **For implementer:** 迁移类任务以「上游绿→本线绿」为验收（不是 TDD 场景）；新功能类任务严格 TDD（先红后绿）。每个任务绿了立刻 commit。
> **Goal:** 把上游 v0.7.24/v0.7.25 全部 Android 适用更新、origin/main QQ 批次 38 提交迁入发布线，并新增「快捷键显示」（默认关、键鼠接入自动开），一版发 v0.7.22-android.290。
> **Architecture:** 发布线 `android-0.7.22` 上分批落地：新样式 final-state checkout、fix 批逐提交 cherry-pick、QQ 批次按拓扑序 cherry-pick；快捷键显示 = zustand 三态 store + Capacitor 原生 InputDeviceListener + resolver + 组件受控。
> **Tech Stack:** React + zustand + TS + Vite（Web 层）；Capacitor + Java（Android 壳）；three.js/pixi.js（可视化）；vitest（测试）。
> **设计文档:** `docs/plans/2026-10-31-upstream-0.7.24-25-qq-shortcut-hints-design.md`（决策记录/风险表在 §6，动手前必读）。
